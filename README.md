# Obsidian Docs PR Test

Tiny repository for testing a PM-friendly documentation workflow:

1. Edit Markdown in Obsidian.
2. Paste or link images.
3. Publish through Enveloppe as a GitHub pull request.
4. Let a developer review and merge.

Open this folder as an Obsidian vault:

```text
/Users/javier/GitHub/obsidian-docs-pr-test
```

The sample documentation lives in `docs/`.
